# cubrid-client v1.2.0

Proposed user-facing notes for the reviewed 1.2.0 release candidate.
**The version is not published or certified production-ready.** Reconcile
these entries with the final Release Please PR, immutable tag and npm tarball
before publication.

## Highlights

- Add opt-in TLS to SSL-enabled CUBRID brokers.
- Add connection-string parsing and SQL query helpers.
- Add optional inactivity-based `readTimeout`, preserving previous behavior
  when unset or `0` ([#128](https://github.com/cubrid-lab/cubrid-client/pull/128)).
- Improve connection recovery, frame parsing, and server-side query-handle
  cleanup when a query fails.

## Fixes

- Preserve signed 64-bit BIGINT values as JavaScript `bigint` instead of
  silently returning `null` ([#126](https://github.com/cubrid-lab/cubrid-client/pull/126)).
- Correct CAS statement type identifiers without changing normal SELECT/DML
  behavior ([#130](https://github.com/cubrid-lab/cubrid-client/pull/130)).
- Correct SQL string escaping for the negotiated server setting and
  serialize shared-connection requests.
- Reject FETCH errors and prematurely incomplete result sets instead of
  silently returning partial rows
  ([#137](https://github.com/cubrid-lab/cubrid-client/pull/137)).
- Reject unsupported non-NULL CUBRID wire types with column/type context
  rather than fabricating a SQL NULL
  ([#140](https://github.com/cubrid-lab/cubrid-client/pull/140)).
- Validate CAS frame bounds and retire damaged connections; prevent a
  lost transaction session from being silently replaced; close query handles
  after decoding/fetch errors
  ([#122](https://github.com/cubrid-lab/cubrid-client/pull/122),
  [#127](https://github.com/cubrid-lab/cubrid-client/pull/127)).

## Compatibility

- Declared Node.js runtime support: **18 and newer**. Build-tool minimums
  are a separate concern.
- CUBRID 10.2–11.4 is a targeted range, **not** a complete required live
  CI-tested matrix ([#95](https://github.com/cubrid-lab/cubrid-client/issues/95)).
- TLS is opt-in, with certificate verification enabled by default.
- `readTimeout` counts inactivity, not total query duration. If it fires,
  the socket is discarded and an executed statement or COMMIT may have an
  **unknown server-side outcome**; the driver does not replay it.

## Known limitations

- Collection and JSON decoding remains unsupported; affected non-NULL values
  **now reject the query** rather than appearing as `null`
  ([#82](https://github.com/cubrid-lab/cubrid-client/issues/82),
  [#110](https://github.com/cubrid-lab/cubrid-client/issues/110),
  [#111](https://github.com/cubrid-lab/cubrid-client/issues/111)).
- FETCH and query-handle fixes have offline regression coverage, but final
  integrated live-broker acceptance remains pending
  ([#129](https://github.com/cubrid-lab/cubrid-client/issues/129),
  [#108](https://github.com/cubrid-lab/cubrid-client/issues/108)).
- CALL/CALL_SP result rows and DML affected-row metadata are not exposed
  by `query()` ([#116](https://github.com/cubrid-lab/cubrid-client/issues/116),
  [#84](https://github.com/cubrid-lab/cubrid-client/issues/84)).
- LOB fields have not been validated as full BLOB/CLOB contents; decoded
  DATE/TIME values depend on the Node process timezone
  ([#93](https://github.com/cubrid-lab/cubrid-client/issues/93),
  [#113](https://github.com/cubrid-lab/cubrid-client/issues/113)).

## Validation and release scope

Offline CI covers Node.js typecheck, unit tests, API declaration checks,
security scans and build. Targeted manual CUBRID checks were reported for
BIGINT (11.4), statement codes (10.2 and 11.4), TLS (11.2) and earlier
frame/query-handle branches; they do **not** prove the final merged release
candidate passes every advertised version and behavior.

The release remains blocked until the required
[release verification](https://github.com/cubrid-lab/cubrid-client/issues/106)
and [production-readiness decision](https://github.com/cubrid-lab/cubrid-client/issues/120)
are reviewed. For complete commits, compare
[v1.1.0 to the proposed v1.2.0](https://github.com/cubrid-lab/cubrid-client/compare/v1.1.0...v1.2.0)
**only after** the tag exists.
