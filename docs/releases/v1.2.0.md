## v1.2.0 (2026-11-07)

Correctness and reliability update for the native CUBRID driver, with opt-in TLS, connection utilities and stronger failure handling.

### Upgrade notes

- Node.js 18 or newer remains supported. This release preserves the 1.x runtime floor.
- String parameters still use escaped SQL literals rather than the optional server-side prepared binding added later in v1.3.0. An interrupted statement or COMMIT can have an unknown server-side outcome and is not blindly retried.
- The release process exercised CUBRID 10.2, 11.0, 11.2 and 11.4 and a real TLS-enabled broker. These checks are scoped evidence, not exhaustive protocol or production-readiness certification.

### Features

- Add opt-in TLS/SSL connections to compatible CUBRID brokers ([#55](https://github.com/cubrid-lab/cubrid-client/pull/55)) by @yeongseon
