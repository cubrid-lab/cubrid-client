# cubrid-client v1.2.0

A focused correctness and reliability update. **This release does not certify full production readiness or a complete CUBRID version matrix.**

## Highlights

- Add optional TLS connections to SSL-enabled CUBRID brokers.
- Add connection-string parsing and SQL query helpers.
- Improve recovery from released CAS connections, EPIPE, and certain connection failures.

## Fixes

- Preserve signed 64-bit CUBRID `BIGINT` values as JavaScript `bigint` instead of silently returning `null` ([#126](https://github.com/cubrid-lab/cubrid-client/pull/126)).
- Correct CUBRID statement type identifiers; ordinary SELECT and DML result behavior is unchanged ([#130](https://github.com/cubrid-lab/cubrid-client/pull/130)).
- Correct SQL string parameter escaping for the server's `no_backslash_escapes` mode ([#52](https://github.com/cubrid-lab/cubrid-client/issues/52)).
- Prevent request interleaving on shared connections and correct the TLS handshake deadlock.

## Compatibility

- Declared Node.js runtime support: **18 and newer**. Build-tool requirements are separate.
- The repository advertises CUBRID 10.2–11.4, but a full independently run live CI matrix has **not** been established ([#95](https://github.com/cubrid-lab/cubrid-client/issues/95)).
- TLS remains opt-in. Certificate verification is enabled by default when TLS is selected.

## Known limitations

- Collection and JSON value decoding is incomplete; some unsupported non-NULL wire types can be returned as `null` ([#82](https://github.com/cubrid-lab/cubrid-client/issues/82), [#110](https://github.com/cubrid-lab/cubrid-client/issues/110), [#111](https://github.com/cubrid-lab/cubrid-client/issues/111)).
- Some FETCH errors may be interpreted as end-of-results, potentially returning incomplete rows without an error. This must be resolved or explicitly accepted in the release decision ([#129](https://github.com/cubrid-lab/cubrid-client/issues/129)).
- `query()` does not return CALL/CALL_SP rows, and DML affected-row metadata is not exposed ([#116](https://github.com/cubrid-lab/cubrid-client/issues/116), [#84](https://github.com/cubrid-lab/cubrid-client/issues/84)).

## Validation and release scope

Offline CI validates type checking, unit tests, and the package build. Targeted live tests have been reported for BIGINT with CUBRID 11.4, statement codes with 10.2 and 11.4, and TLS with 11.2; these do **not** establish complete live support coverage. Review the [release verification task](https://github.com/cubrid-lab/cubrid-client/issues/106) and [production-readiness gate](https://github.com/cubrid-lab/cubrid-client/issues/120) before publishing.

For the complete commit-by-commit list, see the [v1.1.0...v1.2.0 comparison](https://github.com/cubrid-lab/cubrid-client/compare/v1.1.0...v1.2.0).
