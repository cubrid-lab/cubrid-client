## v0.2.0 (2026-03-13)

Maintenance release of the original `node-cubrid`-backed adapter. This tag exists, but no separate GitHub Release page has been published for it.

### Upgrade notes

- Node.js 18 or newer remains the declared runtime requirement. The native CAS driver is **not** part of v0.2.0.
