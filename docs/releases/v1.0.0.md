## v1.0.0 (2026-03-14)

Major architectural release replacing the `node-cubrid` adapter with a native TypeScript implementation of the CUBRID CAS protocol.

### Upgrade notes

- The external `node-cubrid` runtime dependency is removed. Applications relying on adapter-specific behavior should validate migration explicitly; this is not a claim of drop-in parity.
- Node.js 18 or newer remains required. This historical release was not protected by the later live CUBRID 10.2/11.0/11.2/11.4 validation matrix.

### Features

- Implement the native CAS binary protocol connection and query adapter ([37525d0](https://github.com/cubrid-lab/cubrid-client/commit/37525d0)) by @yeongseon
- Add manual transaction methods to the client ahead of the native adapter transition ([0a7684a](https://github.com/cubrid-lab/cubrid-client/commit/0a7684a)) by @yeongseon

### Documentation

- Add API reference, connection and troubleshooting guides for the new client implementation ([3cabdcd](https://github.com/cubrid-lab/cubrid-client/commit/3cabdcd), [c58e4fc](https://github.com/cubrid-lab/cubrid-client/commit/c58e4fc)) by @yeongseon
