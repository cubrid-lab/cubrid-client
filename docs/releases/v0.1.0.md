## v0.1.0 (2026-03-13)

Initial TypeScript/Node.js release of the Promise-based CUBRID client. This version wraps the existing `node-cubrid` driver; it does not contain the native CAS implementation introduced in v1.0.0.

### Upgrade notes

- Requires Node.js 18 or newer and the `node-cubrid` runtime dependency. Typed query results are a TypeScript convenience, not runtime value validation.
- This initial tag has no established live multi-version CUBRID validation matrix.

### Features

- Introduce `createClient()`, typed `query<T>()`, transaction callbacks and structured connection/query/transaction errors by @yeongseon
- Provide ESM and CommonJS package entry points by @yeongseon
