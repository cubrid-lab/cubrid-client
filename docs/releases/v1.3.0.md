## v1.3.0 (2026-11-07)

This release adds streaming, schema inspection and transaction options to the TypeScript/Node.js CUBRID client, together with protocol and transaction correctness fixes.

### Upgrade notes

- Node.js 18 and newer remain supported throughout the 1.x line. This release does not raise the minimum runtime version.
- Existing `query()` behavior remains available; `stream()` and server-side prepared binding are opt-in. Custom connection implementations must support an optional capability before callers can use it.
- The release checks passed with CUBRID 10.2, 11.0, 11.2 and 11.4, real TLS, and packaged ESM/CJS consumers on Node.js 18/20/22. The [publication workflow](https://github.com/cubrid-lab/cubrid-client/actions/runs/42386689234) verified npm publication of `cubrid-client@1.3.0`. These tests do not establish compatibility with every type, fault or broker configuration.

### Features

- Stream large query results with bounded buffering and cursor cleanup through `stream()` ([#212](https://github.com/cubrid-lab/cubrid-client/pull/212)) by @yeongseon
- Inspect tables, columns, primary keys and indexes through read-only schema APIs ([#206](https://github.com/cubrid-lab/cubrid-client/pull/206)) by @yeongseon
- Configure transaction isolation and lock timeouts, including restoration after session replacement ([#209](https://github.com/cubrid-lab/cubrid-client/pull/209)) by @yeongseon
- Enable optional server-side prepared parameter binding ([#207](https://github.com/cubrid-lab/cubrid-client/pull/207)) by @yeongseon
- Access result-column metadata, affected-row counts, last-insert IDs and the server version ([#198](https://github.com/cubrid-lab/cubrid-client/pull/198), [#192](https://github.com/cubrid-lab/cubrid-client/pull/192), [#193](https://github.com/cubrid-lab/cubrid-client/pull/193)) by @yeongseon
- Read BLOB/CLOB content and decode timezone-aware values; JSON continues to be returned as text ([#194](https://github.com/cubrid-lab/cubrid-client/pull/194), [#204](https://github.com/cubrid-lab/cubrid-client/pull/204)) by @yeongseon
- Improve structured diagnostics, error reporting and failed TCP connection retries ([#182](https://github.com/cubrid-lab/cubrid-client/pull/182), [#183](https://github.com/cubrid-lab/cubrid-client/pull/183), [#191](https://github.com/cubrid-lab/cubrid-client/pull/191)) by @yeongseon

### Bug Fixes

- Reject incomplete EXECUTE/FETCH responses and damaged or unsupported values instead of returning incorrect results ([#213](https://github.com/cubrid-lab/cubrid-client/pull/213), [#187](https://github.com/cubrid-lab/cubrid-client/pull/187), [#177](https://github.com/cubrid-lab/cubrid-client/pull/177)) by @yeongseon
- Preserve years 1–99 in dates and reject invalid zero dates ([#211](https://github.com/cubrid-lab/cubrid-client/pull/211), [#186](https://github.com/cubrid-lab/cubrid-client/pull/186)) by @yeongseon
- Decode collections and empty BIT values without corrupting adjacent columns ([#167](https://github.com/cubrid-lab/cubrid-client/pull/167), [#197](https://github.com/cubrid-lab/cubrid-client/pull/197)) by @yeongseon
- Protect transaction completion, health checks and server-initiated abort handling ([#164](https://github.com/cubrid-lab/cubrid-client/pull/164), [#181](https://github.com/cubrid-lab/cubrid-client/pull/181), [#195](https://github.com/cubrid-lab/cubrid-client/pull/195)) by @yeongseon
- Serialize shared-session statements and preserve CAS state and escaping configuration across requests ([#169](https://github.com/cubrid-lab/cubrid-client/pull/169), [#205](https://github.com/cubrid-lab/cubrid-client/pull/205), [#188](https://github.com/cubrid-lab/cubrid-client/pull/188)) by @yeongseon
- Bound handshake timeouts and reject queries on closed clients ([#199](https://github.com/cubrid-lab/cubrid-client/pull/199), [#200](https://github.com/cubrid-lab/cubrid-client/pull/200)) by @yeongseon
