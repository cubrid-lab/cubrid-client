## v1.1.0 (2026-03-17)

A focused patch-level update to SQL parameter formatting, TypeScript checks and developer documentation. Connection-string parsing and query helpers were committed **after** this tag and are not part of v1.1.0.

### Upgrade notes

- Node.js 18 or newer remains required. The published tag did not establish a complete live multi-version CUBRID validation matrix.
- This update does not establish full compatibility for all CAS wire types, fault scenarios or connection states.
