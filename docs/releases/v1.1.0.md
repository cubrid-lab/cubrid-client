# cubrid-client v1.1.0

Published: 2026-03-17. Historical note corrected on 2026-11-06 against the actual v1.1.0 tag. The original GitHub Release description is not changed by this file alone.

## Highlights

- Improve SQL parameter interpolation handling for comments and UTC date values.
- Resolve strict TypeScript compilation errors in tests.
- Refresh development documentation and workflow dependencies.

## Fixes

- Correct comment parsing in parameter interpolation and normalize date serialization to UTC.
- Fix strict TypeScript test errors and update a failing badge-sync workflow action reference.

## Compatibility

- Declared Node.js runtime support: 18 and newer.
- No complete live CUBRID version matrix was established by the tagged CI.
- URL-style connection parsing and query helpers **were not included in the v1.1.0 tag**; their implementation commit came later and belongs in a subsequent release.

## Known limitations

- The native CAS driver still had correctness and feature-coverage gaps later identified in [#81](https://github.com/cubrid-lab/cubrid-client/issues/81), [#82](https://github.com/cubrid-lab/cubrid-client/issues/82), and [#110](https://github.com/cubrid-lab/cubrid-client/issues/110).
- Neither a minor version nor a passing offline suite establishes production readiness.

## Validation and release scope

The v1.1.0 tag contains the fixes above. This historical update corrects release claims without rewriting the immutable tag or implying additional live tests.
